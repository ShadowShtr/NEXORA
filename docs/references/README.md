# Referências visuais

Imagens de referência por ecrã (pixel-perfect), uma por ficheiro, nomeadas conforme os
títulos das secções em `../UI_SCREEN_SPECIFICATIONS.md` (ex.: `10-dashboard.png`,
`11-agenda-dia.png`). Nunca comprimir/reescalar antes de guardar — o processo de QA
visual (`../VISUAL_QA_PLAYBOOK.md`) compara pixel a pixel contra estas imagens.
