# ADR-003 — WhatsApp por deep link manual

## Estado

Aceite

## Decisão

Não usar API paga do WhatsApp no MVP. A NEXORA abre o chat com texto pronto; a dona envia e marca manualmente.

## Consequências

Sem custo por mensagem e onboarding simples, mas sem confirmação automática de envio, entrega ou leitura.
